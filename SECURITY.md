# Security

Launchway is early software. In particular, **the web UI and its API have no sign-in yet**. Keep
the server on `localhost` (the default) or behind something that authenticates, and do not expose it
to an untrusted network.

## Reporting a problem

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/launchway-dev/launchway/security/advisories/new)
rather than in a public issue. We will acknowledge the report and keep you informed.
