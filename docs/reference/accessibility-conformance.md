# Accessibility conformance statement

A statement in the form of the Voluntary Product Accessibility Template (VPAT): each criterion of WCAG 2.2 levels A and AA, whether the web interface supports it, and what is behind the answer. It is a draft, written by the people who build the product from what is tested, not an audit by someone else. It is for people who buy, review or use Launchway. The plain-language page is [Accessibility](../guide/accessibility.md).

This page is generated by `web/scripts/a11y-conformance.mjs` from the contrast test, the last browser scan and keyboard run, and the baselines of open findings; `make check` fails if it is out of date. The judgments in the remarks are written beside each criterion in that script.

## Product

| Item | Detail |
|---|---|
| Product | Launchway web interface |
| Standard | WCAG 2.2 level AA (which Section 508 and EN 301 549 point to for web content) |
| Last recorded run | 2026-11-21 |
| Open findings | 1 (definition-list) |
| Not evaluated | A screen reader on a physical device, Windows high contrast on Windows, Safari and Firefox (the scans use Chromium) |

Terms: **Supports** means no known problem and tested as far as the remarks say. **Partially supports** means a known gap, named. **Does not support** means the criterion is not met. **Not applicable** means the product has nothing the criterion is about.
